# Loy Krathong ๒๕๖๙ · Online — วิธีเปิดใช้ "แม่น้ำรวม"

เว็บนี้ใช้ได้ 2 แบบ

| แบบ | ทำอย่างไร | ได้อะไร |
|---|---|---|
| **A. ไฟล์เดียว** | ลาก `index.html` + `bgm.mp3` ขึ้น Netlify Drop | ใช้ได้ทุกอย่าง ยกเว้นแม่น้ำรวมและยอดรวม (หน้าเว็บซ่อนส่วนนี้เอง) |
| **B. เต็มรูปแบบ** | ทำตามขั้นตอนด้านล่าง | ทุกคนเห็นกระทงของกัน + ยอดรวมทั้งประเทศ |

---

## แบบ B: ขั้นตอน (ประมาณ 15 นาที)

### 1) Supabase
1. เข้า supabase.com → New project (ตั้งรหัสผ่านฐานข้อมูลเก็บไว้)
2. เมนู **SQL Editor** → วางเนื้อหาไฟล์ `supabase.sql` ทั้งไฟล์ → กด **Run**
3. เมนู **Project Settings → API** จดไว้ 2 ค่า
   - `Project URL` (เช่น `https://xxxx.supabase.co`)
   - **Secret key** (`sb_secret_...`) หรือถ้าเป็นโปรเจกต์เก่าใช้ `service_role` ก็ได้ (**ห้ามใส่ในหน้าเว็บ / ห้ามแชร์** ใช้เฉพาะใน Netlify เท่านั้น)

### 2) Netlify
ฟังก์ชันหลังบ้าน (`netlify/functions`) **อัปแบบลากวางไม่ได้** ต้องใช้วิธีใดวิธีหนึ่ง
- **GitHub (แนะนำ):** อัปทั้งโฟลเดอร์นี้ขึ้น GitHub repo → Netlify → Add new site → Import from Git
- **Netlify CLI:** `npm i -g netlify-cli` → `netlify login` → ในโฟลเดอร์นี้ `netlify deploy --prod`

จากนั้น **Site configuration → Environment variables** เพิ่ม
| Key | Value |
|---|---|
| `SUPABASE_URL` | Project URL จากข้อ 1 |
| `SUPABASE_SERVICE_KEY` | Secret key (`sb_secret_...`) จากข้อ 1 |
| `IP_SALT` | ข้อความสุ่มอะไรก็ได้ เช่น `loy-2569-xyz` |

กด **Deploys → Trigger deploy** อีกครั้งให้ค่ามีผล

### 3) ตรวจว่าใช้ได้
- เปิด `https://<เว็บของคุณ>/api/river` ต้องเห็น `{"items":[...],"total":..}`
- เปิดหน้าเว็บ จะมีป้ายสีเขียว "ลอยแล้วทั้งประเทศ …" ใต้ปุ่ม

## ⚠️ ค่าใช้จ่ายถ้าคนเข้า 100,000 คน (อ่านก่อนขึ้นจริง)
Netlify แพ็กเกจฟรีมี **300 เครดิต/เดือน และเป็นเพดานแข็ง** ใช้หมดเว็บจะหยุดให้บริการ
ประมาณการ 100,000 คน (อยู่คนละ ~10 นาที, เปิดเพลง ~30%):
| รายการ | ปริมาณ | เครดิต (โดยประมาณ) |
|---|---|---|
| หน้าเว็บ 35 KB × 100k | ~3.5 GB | |
| เพลง 300 KB × 30k คน | ~9 GB | |
| ดึงแม่น้ำทุก 60 วิ ~10 ครั้ง/คน | ~2.5 GB | |
| **รวม bandwidth** | **~15 GB** | **150–300** |
| คำขอทั้งหมด ~1.2 ล้านครั้ง | | ~250 |
| ฟังก์ชันหลังบ้าน | | < 50 |
| **รวม** | | **~450–600 → เกินแพ็กเกจฟรี** |

**แนะนำ:** อัปเป็น Netlify **Pro (3,000 เครดิต)** ช่วงเดือนพฤศจิกายน แล้วลดกลับหลังงาน
และดูยอดใช้ที่ Netlify → Usage ทุกวันช่วงใกล้วันงาน

Supabase แพ็กเกจฟรีพอ: 100,000 แถว ≈ 50–100 MB (เพดาน 500 MB) และคำขอไม่จำกัด
(แพ็กเกจฟรีไม่มี backup อัตโนมัติ — ถ้าข้อมูลสำคัญ export เก็บหลังงาน)

## รองรับคนเยอะได้อย่างไร
- หน้าเว็บดึง `/api/river` ทุก 60 วินาที (หยุดเองเมื่อไม่มีการใช้งาน 30 นาที หรือสลับไปแอปอื่น) แต่ Netlify **เก็บแคช 15 วินาที** → คนเข้าหมื่นคน ฐานข้อมูลถูกเรียกแค่ราว 4 ครั้ง/นาที
- เพลงแยกเป็นไฟล์ `bgm.mp3` โหลดเฉพาะคนที่เปิดเสียง
- ถ้าฐานข้อมูลยุ่ง หลังบ้านตอบ "busy" แทนการล่ม และหน้าเว็บส่งซ้ำให้อัตโนมัติ 2 ครั้ง
- ไม่ใช้ Realtime ของ Supabase จึงไม่ติดเพดานจำนวนคนต่อพร้อมกัน
- ลอยได้ไม่เกิน 5 ครั้ง/นาที/เครื่อง (กันสแปม)

## ความปลอดภัยและการดูแลข้อความ
- ฐานข้อมูลปิดสิทธิ์สาธารณะทั้งหมด (RLS) เข้าถึงได้เฉพาะฟังก์ชันหลังบ้าน
- คำหยาบถูกแทนด้วย `***` อัตโนมัติ (เพิ่มคำได้ที่ `netlify/lib/shared.mjs` ตัวแปร `BAD`)
- คำอธิษฐานที่มีลิงก์ / เบอร์โทร / LINE ID จะไม่แสดง
- ผู้ใช้กด 🚩 รายงานได้ ครบ 3 ครั้งข้อความจะถูกซ่อนเอง
- ซ่อนเองด้วยมือ: Supabase → Table Editor → `krathongs` → ติ๊ก `hidden` = true
- เก็บ IP แบบเข้ารหัสทางเดียว (hash) เพื่อกันสแปมเท่านั้น ไม่เก็บ IP จริง

## ไฟล์ในชุดนี้
```
index.html                    หน้าเว็บ (ใช้แบบ A ได้ทันที)
bgm.mp3                       เพลงประกอบ (โหลดเมื่อเปิดเสียง)
netlify.toml                  ตั้งค่า Netlify
netlify/functions/river.mjs   GET  /api/river  กระทงล่าสุด + ยอดรวม (มีแคช)
netlify/functions/float.mjs   POST /api/float  บันทึกกระทง/โคม
netlify/functions/report.mjs  POST /api/report รายงานข้อความ
netlify/lib/shared.mjs        ตัวช่วย: กรองคำ, ตรวจข้อมูล, hash IP
supabase.sql                  สร้างตาราง + ฟังก์ชันในฐานข้อมูล
```
